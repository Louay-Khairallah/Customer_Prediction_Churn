# Customer Churn Prediction

A machine learning project that analyzes customer data and predicts whether a customer is likely to churn.

## Overview

Customer churn is an important problem for subscription-based businesses. The goal of this project is to use customer and service-related data to identify patterns associated with churn and build a machine learning model capable of predicting customers who are likely to leave.

## Objectives

* Explore and understand customer data
* Identify factors associated with customer churn
* Prepare and preprocess the dataset
* Train machine learning models
* Evaluate model performance
* Analyze the factors that contribute to customer churn

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab
* Jupyter Notebook

## Project Workflow

The notebook follows these main steps:

1. Data loading
2. Exploratory data analysis
3. Data cleaning and preprocessing
4. Feature preparation
5. Model training
6. Model evaluation
7. Analysis of predictions and important features

## Getting Started

### Using Google Colab

Open the notebook with Google Colab and run the cells sequentially.

### Running Locally

Install the required dependencies:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

Then open the notebook:

```bash
jupyter notebook churn_prediction.ipynb
```
